Phase 3 · Foundations

3a — Colour

Six ramps, nineteen semantic names, and a matrix that says what every pair actually measures.

Nothing here was chosen by eye. Each ramp is built in OKLCH on one shared lightness ladder, with chroma reduced only where sRGB cannot hold it, so hue and lightness stay exact across all six families. The semantic layer then points at ramp steps — and where a pairing failed its floor, the ladder was solved rather than the swatch nudged. The first build failed eight pairs; one ladder value and two remappings fixed all eight.

The ladder is deliberately uneven — tight at both ends, wide through the middle. Dark-mode surfaces need closely-spaced dark steps because tone is the only elevation mechanism this system has; body text needs wide spacing in the middle to clear its contrast floors. A linear ramp cannot do both.

One rename to approve or reject. The brief named the text aliases text, text-muted, text-faint, and the token source keeps those names. But Tailwind derives utilities from token names, so those would generate text-text-muted. The Tailwind theme therefore emits them as fg, fg-muted, fg-faint — giving text-fg-muted. It is the one place a token is called two things, and it is worth it or it is not. Logged as D-017.
