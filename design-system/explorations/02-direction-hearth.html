Phase 2 · Direction

Hearth

Warm ground, cool accent. Soft light does the lifting.

Hearth is the one that keeps the company's existing blue and puts it somewhere unexpected: on a warm, brown-tinted neutral rather than the blue-grey every dark UI defaults to. That single move is what stops #3b82f6 from reading as generic — the accent stays cool and institutional while the ground stays soft. It is also the only direction that uses shadow, and it uses exactly two steps: resting and raised. Radii are the largest of the three. This is the most tactile option and the only one with brand continuity to d3cloud.io already built in.

Focus ring
One rule worth naming. The brief says the language is fills, not outlines — but a form control still needs a boundary a sighted user can find before focusing it (WCAG 1.4.11, 3:1). So in all three directions, fields carry a 3:1 field border and nothing else does. Cards, chips, badges, tabs and the table are pure fills. This is the same distinction Bindery arrived at independently with its edge / field split, and it is the one place the system is deliberately not flat.
One thing these directions get wrong on purpose, for now. The priority dot in the table carries its meaning by colour alone. All four steps now clear 3:1, so they are visible — but a colourblind user still cannot tell critical from high. The fix belongs in the component spec, not the palette: priority needs a shape or a label alongside the hue. Flagged for Phase 4.
