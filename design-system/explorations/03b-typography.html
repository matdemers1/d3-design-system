3b — Typography

Four candidates, one dense screen, and the numerals that actually matter.

Not one of the four apps loads the typeface it declares — App A asks for Inter and renders Helvetica. So this is a real choice with no incumbent to defend. All four candidates below are SIL OFL, variable, and self-hosted here as embedded latin subsets, which is exactly how they would ship. Each renders the same block: a data table with numbers that must align, form labels, two validation errors, an empty state, and a paragraph long enough to judge.

Measured, not asserted x-height and width read off the rendered glyphs, not the marketing

x-height is the whole argument at these sizes. This system's smallest step is 11px and it uses 12px heavily — table metadata, reference IDs, validation errors, uppercase headers. At 11px Inter's lowercase measures 6.00px tall and Figtree's measures 5.50px: the same nominal size, 8.4% less actual letter. That difference is invisible in a heading and decisive in a table. Inter is measurably the most legible of the four at the sizes this system actually spends its time — and it is also the most anonymous, which the brief lists as a non-goal. Geist gives up 2.9% of x-height for noticeably more character. That is the real trade.

Look down the columns, not along the rows. Both tables are right-aligned, so the last digit lines up either way — that is not the problem. The problem is everything to the left of it: with proportional figures a 1 is narrower than an 8, so the thousands and hundreds columns wander from row to row. Measured on these four faces, all-ones versus all-eights differs by 2.0–2.6em across ten digits.

Every number in this system is in a column. Votes, byte counts, page counts, durations, dates. And Bindery and App A both poll, so a proportional value visibly jitters in place when it updates. font-variant-numeric: tabular-nums is therefore not a per-component choice — it is on by default for every numeric cell. All four candidates support it.

Seven sizes, and the top of the scale is 24px. The audit found nineteen sizes across the four apps with ten of them crammed between 10 and 15px. This scale has four steps in that band and they are 11, 12, 13, 14 — each with a distinct job, none of them a near-duplicate. There is no display size because the brief rules out typographic performance: emphasis is weight, so 14px/600 outranks 16px/400.

This paragraph is set at the body measure — 65 characters — at 14px with a 1.55 line height. Anything longer than about 75 and the eye loses the start of the next line; anything shorter than about 45 and it jumps too often. The archive's help text, the trust page and every empty state live inside this.
